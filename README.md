# RR Home Tuition Website

A single-page website for RR Home Tuition in Jagdev Nagar, Mango, Jamshedpur.

## Publish with GitHub Pages

1. Create a public repository named `rr-home-tuition`.
2. Push the contents of this folder to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The site entry point is `index.html`. The `.nojekyll` file tells GitHub Pages to serve the static site directly. Images, web fonts and some visual effects load from external services and require an internet connection.
